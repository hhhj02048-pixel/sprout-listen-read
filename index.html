为什么这样设计

RATIONALE
决策理由
一个页面两个 Tab，而不是两个入口听与读在语言学习里是同一件事的两面（输入的两条通道）。分开做入口会让首页变成功能罗列——这正是前 7 版被否掉的原因。
用"点亮 / 收集"替代"正确率 / 分数"小学生看不懂分数，但看得懂"灯亮了、花又多了一朵"。奖励必须可见、可累计，直接接回花园系统。
答题只做三选一目标用户是小学生，选项一多就乱。四选一/拼写属于更高年级，留到 Lv.4 以后解锁。
阅读用中英对照而不是纯英文过渡期读物（Level 1–2）需要中文做脚手架；Level 3 起自动隐藏中文行，按水平渐进。
错误不惩罚用金币惩罚会造成"不敢答"。改为"不扣分 + 自动慢速重播 + 相似词对比"，把错误变成教学点。
二级页不放底部 Tab底部 Tab 保留给词库 / 花园 / 伙伴 / 勋章四个主场景；听读是任务页，专注完成任务后立刻返回，避免中途分心。
